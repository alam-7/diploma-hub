## 💚 Code of Conduct

By participating in this project, you agree to:

- **Be respectful** — no personal attacks, harassment, or discrimination
- **Be constructive** — give helpful feedback, not just criticism
- **Be patient** — maintainers are volunteers
- **Be inclusive** — welcome students of all backgrounds and skill levels
- **Focus on the goal** — help Diploma students learn better

Violations may result in a ban from the repository.

## 🎯 Ways to Contribute

You don't need to be a coder! Here are all the ways you can help:

| Type | Difficulty | Examples |
|------|-----------|----------|
| 🐛 **Report bugs** | Easy | Broken link, wrong content, layout issue |
| 💡 **Suggest features** | Easy | New section, better UX, new tool |
| ✏️ **Fix typos** | Easy | Spelling, grammar, formatting |
| 📝 **Add content** | Medium | Notes, papers, practicals |
| 🎨 **Improve UI** | Medium | Better colors, spacing, animations |
| 🔧 **Fix code** | Medium | JS bug, CSS issue, broken feature |
| 🌐 **Translate** | Medium | Marathi, Hindi, other languages |
| 📚 **Add new subjects** | Hard | Full syllabus for a new branch |
| 🚀 **Build features** | Hard | New pages, backend APIs |
| ⭐ **Spread the word** | Easy | Share on social media, tell friends |

## 🚀 Quick Start

### For content contributors (no code)

1. **Open an issue** describing what you want to add
2. Attach files or paste content
3. A maintainer will review and merge

### For developers

```bash
# 1. Fork the repo (button at top-right on GitHub)

# 2. Clone your fork
git clone https://github.com/YOUR-USERNAME/diploma-hub.git
cd diploma-hub

# 3. Add upstream remote
git remote add upstream https://github.com/alam-7/diploma-hub.git

# 4. Create a branch
git checkout -b feature/your-feature-name

# 5. Make changes
# ... edit files ...

# 6. Commit
git add .
git commit -m "feat: add XYZ feature"

# 7. Push
git push origin feature/your-feature-name

# 8. Open a Pull Request on GitHub
